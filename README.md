# 💘 Valentine Wish App

A sweet and interactive **Valentine Wish App** built with **React + Vite**, designed to help users create a beautiful and personalized Valentine page for their partner 💝

---

## ✨ Features
- ❤️ Create a personalized Valentine page
- 🌸 Friendly and simple user flow
- 💫 Smooth animations and transitions
- 📱 Fully responsive design
- ⚡ Super fast performance with Vite

---

## 🛠 Tech Stack
- **React** – UI development
- **Vite** – Fast build tool with HMR
- **CSS** – Custom styling & animations
- **ESLint** – Code quality and consistency
